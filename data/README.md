# Data

`raw/` and `processed/` are gitignored — datasets don't belong in version
control. Download the datasets referenced in the proposal (Section 16) and
place them here:

- `raw/pima_diabetes.csv` — Pima Indians Diabetes Dataset
- `raw/uci_heart_disease.csv` — UCI Heart Disease Dataset (Week 9-10 stretch goal)

`processed/` is where cleaned/feature-engineered versions go, produced by
the notebooks in `ml-notebooks/`.
